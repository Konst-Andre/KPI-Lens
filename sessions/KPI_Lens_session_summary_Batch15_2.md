# KPI Lens — Session Summary — Batch 15.2

## Що зроблено

**1. Звірка реальних даних (5 аптек, з адресами).**
Витягнуто з `KPI.xlsx` (лист IMS) 5 реальних аптек АНЦ/Дніпро з адресами,
категоріями OTC/IW і показниками IMS (Кві/Тра/Чер 2026) для звірки з HT-email.
Колонка адреси — IMS `E = "Outlet Address"` (минулого разу була пропущена).

**2. Діагностика бага Tests = 0.**
Симптом: у джерелі Tests є (напр. Слави 3Р — 318/166/55 грн), на сайті — нуль.
Хибна перша гіпотеза («дані не тягнуться») відкинута: PQ (`IMS_грн`, `Export_IMS_грн`)
і VBA (`ims_tst_arr`/`off_tst_arr`, `SerializePharmacy` з `tst:[]`) тягнуть Tests **коректно**.
**Реальна причина — `fmtK`:** значення у тисячах, `toFixed(0)` округлював малі суми
(<500 грн) до «0 K». OTC 6879→«7 K», IW 2800→«3 K», Tests 55/166/318→«0 K».
Підтверджено симуляцією на реальних числах Слави 28.

**3. Batch 15.2 — preview `KPI_Lens_v2_preview_batch15_2.html` (2 фікси):**

- **`fmtK` Варіант A:** `≥1M → X.XX M` · `≥1000 грн → ціле «7 K»` · `<1000 грн → реальні грн «318 ₴»` · `0 → "0"`. Малі суми більше не зникають.
- **Tab-3 SKU-таблиця:** прибрано малочитабельний спарклайн («крякозябру», 50×18px).
  Лишилась %-дельта «vs {попередній}». Колонки: `# | SKU | [місяці] | vs {попередній}`.
  `colspan` empty-state `n+4 → n+3`; мертвий `const sc` видалено;
  `spark()` **лишився** (використовується у breakdown-картках, рядки ~988/1307).

**4. Template `KPI_Lens_template_v2.html` — створено з нуля.**
Раніше фізично не існував (перевірено `ls`, не маніфест). Згенеровано з Batch 15.2:
весь літерал `const DATA = {…};` → `const DATA = /*__DATA__*/;`.
VBA-сумісність підтверджена: `TPL_NAME = "KPI_Lens_template_v2.html"`,
`PLACEHOLDER = "/*__DATA__*/"`, `json` = чистий обʼєкт `{…}` (без префікса `const`).
